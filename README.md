# ポートフォリオサイトの使い方

Web制作・Webデザイン・ライティングの3分野をまとめて紹介できる、1ページ構成のポートフォリオです。

## ファイル構成

```
portfolio/
├── index.html   構成・文章
├── style.css    デザイン
├── script.js    モバイルメニュー / 作品の絞り込み
└── README.md    このファイル
```

## VS Codeでの開き方

1. このフォルダごとVS Codeで開く(「ファイル」→「フォルダーを開く」)
2. 拡張機能「Live Server」を入れると、`index.html` を右クリック →
   「Open with Live Server」でブラウザ確認しながら編集できて便利です
3. 保存すると自動でブラウザが更新されます

## 差し替えが必要な箇所(公開前チェックリスト)

- [ ] `index.html` 内の名前(森 あや / Aya Mori)をご自身の名前に変更
- [ ] `<title>` と `<meta name="description">` を自分用に変更
- [ ] 自己紹介文(about セクション)を実際の経歴に差し替え
- [ ] 「作品・実績」セクションの案件名・担当範囲を実際の内容に差し替え
      - 画像を使う場合は `work-thumb` の中身を `<img>` タグに変更してください
      - 守秘義務がある案件は、社名を伏せて「概要・担当範囲・工夫した点」を書くと信頼されやすくなります
      - 実績がまだ無い場合は、自主制作サイトや模写案件を1〜2件載せるだけでも効果があります
- [ ] 料金の目安を実際の相場に変更(クラウドワークス内の類似案件を見て調整すると安心です)
- [ ] `mailto:your-email@example.com` を実際の連絡先に変更
- [ ] クラウドワークスのプロフィールURLを実際のリンクに変更
- [ ] フッターの年号・名前を変更

## 色を変えたい場合

`style.css` の一番上、`:root` の中にある変数を書き換えると、サイト全体の配色が変わります。

```css
--accent-web:     #3B6E64; /* Web制作のアクセントカラー */
--accent-design:  #C98A2C; /* デザインのアクセントカラー */
--accent-writing: #A6432E; /* ライティングのアクセントカラー */
```

## 公開方法(無料でOK)

- **GitHub Pages**: GitHubにリポジトリを作って push するだけで公開できます
- **Netlify / Vercel**: フォルダをドラッグ&ドロップするだけで公開できます

どちらも無料枠で十分運用できます。公開したURLをクラウドワークスのプロフィール欄に貼ると、
実績のアピールになります。
